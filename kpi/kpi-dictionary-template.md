# KPI Dictionary — Performance Management

A KPI dictionary creates a single source of truth for performance definitions.

| KPI | Purpose | Definition | Formula | Numerator | Denominator | Data Source | Frequency | Owner | Target | Action Trigger |
|---|---|---|---|---|---|---|---|---|---|---|
| | | | | | | | | | | |

## Example: Gross Conversion Rate

**Purpose:** monitor the effectiveness of the operational funnel.

**Definition:** proportion of eligible leads resulting in a gross conversion during the measurement period.

**Formula:**

`Gross Conversion Rate = Gross Conversions ÷ Eligible Leads × 100`

**Governance note:** gross conversion should not automatically be interpreted as net business conversion when leads can be transferred to other service pathways.

## KPI Quality Checklist

Before publishing a KPI, verify:

- [ ] Business purpose is clear.
- [ ] Formula is documented.
- [ ] Numerator and denominator are defined.
- [ ] Inclusion / exclusion rules are explicit.
- [ ] Data source is identified.
- [ ] Owner is accountable.
- [ ] Frequency is defined.
- [ ] Target or reference level exists.
- [ ] Action trigger is agreed.
- [ ] Historical comparability is valid.

## KPI Lifecycle

**Define → Validate → Baseline → Measure → Review → Act → Reassess**
